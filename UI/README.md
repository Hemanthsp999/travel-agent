# Travel Agent UI

This folder contains a small Streamlit console for the travel agent.

## Run

```bash
source .venv/bin/activate
streamlit run UI/app.py
```

Then open the local URL displayed by Streamlit.

## Features

- Submit a query to the orchestrator
- Keep or change a thread ID
- Inspect the final response
- View flow/status metadata
- Review captured logs from the agent runtime
